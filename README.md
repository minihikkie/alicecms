## ทำไมต้องระบบนี้

หน่วยงานราชการส่วนใหญ่ต้องการเว็บไซต์ที่มี ITA, จัดซื้อจัดจ้าง, เอกสารเผยแพร่ และช่องทางร้องเรียน
แต่มักติดปัญหาเดิมๆ — งบไม่พอจ้างดูแลรายปี, โฮสต์ที่ได้มาเป็น shared hosting รุ่นเก่า,
คนดูแลเว็บคือเจ้าหน้าที่ธุรการที่ไม่ได้เรียนสายไอทีมา

ระบบนี้ตอบโจทย์นั้นโดยตรง:

| ปัญหาที่เจอจริง | ระบบนี้จัดการยังไง |
|---|---|
| ไม่มีคนแก้โค้ดให้ | ตั้งค่าทุกอย่างผ่านหน้า admin — เปิด/ปิดเมนู เปลี่ยนสี เปลี่ยนชื่อหัวข้อ |
| โฮสต์ไม่รองรับฟีเจอร์ใหม่ | ตรวจความสามารถเซิร์ฟเวอร์เองแล้ว**ถอยกลับอัตโนมัติ** ไม่ปล่อยให้เว็บล่ม |
| เครือข่ายราชการบล็อกขาออก | ทุกการตรวจสอบมีทางเลือกแบบไม่ต้องต่อเน็ต |
| หน่วยงานไม่มี ITA / จัดซื้อ | ปิด section ทิ้งได้ เมนูหายเอง ไม่เหลือหน้าว่าง |
| อัปเดตทีต้องจ้างคนมาทำ | กดอัปเดตในหน้า admin สำรองอัตโนมัติก่อนทุกครั้ง กู้คืนได้ |

## ความสามารถ

**เนื้อหาและการเผยแพร่**
- ข่าว 3 ประเภท (กิจกรรม / ประชาสัมพันธ์ / ประกาศ) แนบรูปปกและไฟล์ได้หลายไฟล์
- เอกสารเผยแพร่ พร้อมหมวดที่กำหนดเอง (ชื่อ ไอคอน สี ลำดับ)
- ITA / OIT ครบ O1–O43
- จัดซื้อจัดจ้าง — e-bidding, ราคากลาง, ผลการพิจารณา
- วิดีโอ (ฝัง YouTube หรืออัปโหลดเอง) พร้อมหน้าเฉพาะของแต่ละคลิป
- **เนื้อหาแบบกำหนดเอง** — สร้างประเภทเนื้อหาใหม่เองได้ กำหนดฟิลด์เอง โดยไม่ต้องแก้โค้ด
- หน้าเพจอิสระ, FAQ, ลิงก์หน่วยงาน, โครงสร้างองค์กร, ทำเนียบบุคลากร

**บริการประชาชน**
- ร้องเรียนออนไลน์ + ติดตามสถานะด้วยรหัสอ้างอิง
- แบบฟอร์มออนไลน์ที่สร้างเองได้ พร้อมแจ้งเตือนทางอีเมล
- ค้นหาทั่วเว็บ, RSS, sitemap.xml อัตโนมัติ

**สำหรับผู้ดูแล**
- แดชบอร์ดสถิติผู้เข้าชม (ไม่เก็บข้อมูลส่วนบุคคล)
- ถังขยะ — ลบแล้วกู้คืนได้
- สำรองข้อมูลอัตโนมัติตามรอบ + ดาวน์โหลดเก็บเอง
- ยืนยันตัวตนสองชั้น (TOTP) รองรับ Google Authenticator
- บันทึกกิจกรรมผู้ดูแล ตรวจย้อนหลังได้

**งานเบื้องหลัง**
- ธีมสำเร็จรูป 8 ชุด (สี · ฟอนต์ · ความโค้งมุม · เงา ครบทั้งชุด) พร้อมตัวอย่างสดและปรับเองต่อได้ทุกค่า
- ตรวจค่าความต่างของสีตามเกณฑ์ WCAG AA ให้อัตโนมัติขณะเลือกสี
- ภาพฉากหลังเว็บ ทั้งหน้าหรือเฉพาะหัวเว็บ ปรับม่านบัง ความเบลอ และจุดสนใจของภาพได้
- ปรับระดับอนิเมชันได้ 3 ระดับ (จัดเต็ม / น้อย / ปิด)
- PWA — ติดตั้งลงหน้าจอมือถือได้ มีหน้า offline
- SEO: meta, Open Graph, JSON-LD, canonical, sitemap
- URL แบบซ่อน `.php` พร้อมกลไกถอยกลับอัตโนมัติถ้าเซิร์ฟเวอร์ไม่รองรับ

## เริ่มใช้งาน

**ความต้องการขั้นต่ำ**

| รายการ | ขั้นต่ำ |
|---|---|
| PHP | 8.0 ขึ้นไป (แนะนำ 8.2) |
| ส่วนขยาย PHP | `pdo_mysql`, `gd`, `fileinfo`, `mbstring` |
| MySQL / MariaDB | 5.7 / 10.3 ขึ้นไป |
| Web server | Apache (รองรับ `.htaccess`) หรือ Nginx (ตั้งค่าเพิ่ม) |

**ติดตั้ง 3 ขั้นตอน**

```bash
# 1. โหลดโค้ดไปวางที่ web root
git clone https://github.com/minihikkie/alicecms.git
```

```
2. เปิดเบราว์เซอร์ไปที่  https://โดเมนของคุณ/install.php
3. ทำตาม wizard 4 ขั้น — ฐานข้อมูล → ชื่อหน่วยงาน → ธีม → บัญชีผู้ดูแล
```

ตัวติดตั้งจะสร้างฐานข้อมูลให้เอง (ถ้ายังไม่มี) สร้าง `config.php` และล็อกตัวเองเมื่อเสร็จ

> **บน XAMPP** วางโปรเจกต์ที่ `C:\xampp\htdocs\govsite` แล้วเปิด `http://localhost/govsite/install.php`
> ค่ามาตรฐานคือ host `localhost`, user `root`, รหัสผ่านเว้นว่าง
>
> **บนโฮสต์ DirectAdmin** (ไม่มี SSH ทำผ่านหน้าเว็บทั้งหมด) ดู
> **[คู่มือติดตั้งบน DirectAdmin](docs/INSTALL-DirectAdmin.md)** — ละเอียดทีละขั้นพร้อมปัญหาที่พบบ่อย

เข้าหน้าจัดการที่ `https://โดเมน/admin/` — **ไม่มีลิงก์บนหน้าเว็บ ต้องพิมพ์ URL ตรง**

## ระบบอัปเดตในตัว

กดอัปเดตได้จากหน้า admin โดยไม่ต้องขึ้น FTP ขั้นตอนที่ระบบทำให้อัตโนมัติ:

1. ดาวน์โหลดแพ็กเกจแล้ว **ตรวจลายเซ็นดิจิทัล (RSA-SHA256)** — แพ็กเกจที่ไม่ได้เซ็นด้วยกุญแจที่ถูกต้องจะถูกปฏิเสธ
2. สำรองไฟล์ทั้งระบบ + ฐานข้อมูลก่อนแตะอะไร
3. ติดตั้งไฟล์ใหม่ (ข้าม `config.php`, `uploads/`, `storage/` เสมอ)
4. ปรับโครงสร้างฐานข้อมูล — ถ้าล้มเหลวจะรายงานว่าไม่สำเร็จ ไม่กลบเกลื่อน
5. ลบชุดสำรองเก่าที่เกิน 3 ชุด กันพื้นที่เต็ม

**ค่าเริ่มต้นคือปิด** — ระบบจะไม่เชื่อมต่อออกไปไหนจนกว่าคุณจะตั้ง URL เซิร์ฟเวอร์อัปเดตเอง

### ตั้งเซิร์ฟเวอร์อัปเดตของตัวเอง

```bash
# 1. สร้างคู่กุญแจของคุณเอง
openssl genrsa -out tools/release-key/private.pem 2048
openssl rsa -in tools/release-key/private.pem -pubout -out tools/release-key/public.pem

# 2. เอา public key ไปวางแทนที่ค่าเดิมใน includes/updater.php

# 3. build แพ็กเกจ (เซ็นด้วย private key อัตโนมัติ)
php tools/build-release.php "รายละเอียดการเปลี่ยนแปลง"

# 4. อัปโหลด dist/*.zip และ dist/update.json ขึ้นเว็บเซิร์ฟเวอร์ใดก็ได้
#    แล้วกรอก URL ของ update.json ที่หน้า ตั้งค่า → อัปเดตระบบ
```

> ⚠️ **`tools/release-key/private.pem` ห้ามขึ้น git เด็ดขาด** — ใครได้ไฟล์นี้ไปจะปลอมแพ็กเกจอัปเดต
> ให้ทุกเว็บที่ใช้กุญแจคู่นี้ยอมรับได้ทันที ไฟล์นี้ถูกใส่ใน `.gitignore` ไว้แล้ว
> แต่ควรเก็บไว้นอกโฟลเดอร์โปรเจกต์จะปลอดภัยกว่า

## ความปลอดภัย

- รหัสผ่านเข้ารหัสด้วย `password_hash()` (bcrypt) ไม่เก็บ plain text
- ทุก query ใช้ PDO prepared statements — กัน SQL Injection
- ทุก output ผ่าน `htmlspecialchars()` — กัน XSS
- ทุกฟอร์ม POST ตรวจ CSRF token ฝั่งเซิร์ฟเวอร์
- Login ผิด 5 ครั้ง (ต่อชื่อผู้ใช้หรือ IP) ล็อก 15 นาที พร้อมบันทึก log
- Session: regenerate ID หลัง login, cookie `httponly` + `samesite`, หมดอายุ 30 นาที
- ยืนยันตัวตนสองชั้นด้วย TOTP (ไม่บังคับ)
- ไฟล์อัปโหลด: whitelist นามสกุล + ตรวจ MIME จากเนื้อไฟล์จริง + เปลี่ยนเป็นชื่อสุ่ม + ปิดการรัน PHP ใน `uploads/`
- Security headers: CSP พร้อม nonce, X-Frame-Options, X-Content-Type-Options, HSTS

**ข้อควรปฏิบัติ**
- ใช้ HTTPS เสมอบนเซิร์ฟเวอร์จริง
- ตั้งรหัสผ่าน admin ที่คาดเดายาก และเปิด TOTP ถ้าทำได้
- อย่าลบไฟล์ `install.lock`
- อัปเดต PHP/MySQL ให้อยู่ในเวอร์ชันที่ยังมีการสนับสนุน

พบช่องโหว่? กรุณาแจ้งแบบส่วนตัวก่อนเปิดเผยสาธารณะ — ดู [SECURITY.md](SECURITY.md)

## การสำรองข้อมูล

ข้อมูลอยู่ 2 ที่ ต้องสำรอง **ทั้งคู่**

```bash
# ฐานข้อมูล
mysqldump -u root -p gov_website > backup-$(date +%Y%m%d).sql
mysql -u root -p gov_website < backup-20260101.sql     # กู้คืน
```

```
โฟลเดอร์ uploads/  — รูปข่าว เอกสาร โลโก้ ไฟล์แนบร้องเรียน อยู่ในนี้ทั้งหมด
```

ระบบมีสำรองอัตโนมัติตามรอบให้อยู่แล้ว (ตั้งค่าที่หน้า สำรองข้อมูล) แต่ควรดาวน์โหลดเก็บนอกเซิร์ฟเวอร์ด้วย

**กู้คืนบนเครื่องใหม่**

1. วางไฟล์โปรเจกต์ + โฟลเดอร์ `uploads/` ที่สำรองไว้
2. สร้างฐานข้อมูลแล้ว import ไฟล์ `.sql`
3. คัดลอก `config.sample.php` เป็น `config.php` แล้วแก้ค่าให้ตรงเครื่องใหม่
4. สร้างไฟล์ `install.lock` (เนื้อหาอะไรก็ได้) เพื่อปิดตัวติดตั้ง

## โครงสร้างโปรเจกต์

```
├── index.php               หน้าแรก (เรนเดอร์ section ตามการตั้งค่า)
├── install.php             ตัวติดตั้ง (ล็อกตัวเองหลังติดตั้งเสร็จ)
├── version.php             เวอร์ชัน + URL เซิร์ฟเวอร์อัปเดต
├── config.sample.php       ตัวอย่างไฟล์ตั้งค่า (คัดลอกเป็น config.php)
├── theme-kit.css           design system หลัก
├── sw.js / manifest.php    PWA
│
├── includes/
│   ├── init.php            บูตระบบ — โหลด config, session, security headers
│   ├── functions.php       ฟังก์ชันกลาง (url, setting, upload, ฯลฯ)
│   ├── hardening.php       ตรวจความสามารถเซิร์ฟเวอร์ + ถอยกลับอัตโนมัติ
│   ├── updater.php         ระบบอัปเดต + ตรวจลายเซ็น
│   ├── migrations.php      ปรับโครงสร้างฐานข้อมูลอัตโนมัติ
│   ├── header.php/footer.php
│   └── sections/           ส่วนประกอบหน้าแรกแต่ละ section
│
├── admin/                  ระบบจัดการทั้งหมด
├── assets/                 css / js / รูปเริ่มต้น
├── tools/                  สคริปต์ผู้พัฒนา (ไม่รวมในแพ็กเกจ release)
├── uploads/                ไฟล์อัปโหลด — ต้องสำรอง
└── storage/                สำรองอัตโนมัติ ถังขยะ ไฟล์ชั่วคราว
```

**ฐานข้อมูล** — ทุกตารางใช้ `utf8mb4_unicode_ci`

`users` `settings` `sections` `posts` `post_attachments` `documents` `doc_categories`
`ita_items` `procurements` `slides` `faqs` `links` `footer_links` `menu_items`
`complaints` `forms` `form_responses` `videos` `media` `pages`
`content_types` `content_items` `personnel` `org_chart_nodes`
`trash` `page_views` `login_logs` `activity_logs` `password_resets`
