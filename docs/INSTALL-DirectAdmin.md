# ติดตั้ง AliceCMS บนโฮสต์ DirectAdmin

คู่มือนี้เขียนสำหรับโฮสต์ทั่วไปที่ใช้แผงควบคุม **DirectAdmin** ซึ่งเป็นแบบที่หน่วยงานราชการไทย
เช่าใช้กันมากที่สุด ไม่ต้องใช้ SSH ไม่ต้องใช้ Composer ทำผ่านหน้าเว็บของ DirectAdmin ได้ทั้งหมด

> ชื่อเมนูใน DirectAdmin ต่างกันเล็กน้อยตามเวอร์ชันและธีม (Evolution / Enhanced)
> ถ้าหาเมนูตามชื่อในคู่มือไม่เจอ ให้ใช้ช่องค้นหาด้านบนของ DirectAdmin พิมพ์คำที่เป็นตัวหนา

รวมเวลาประมาณ 15–20 นาที

---

## ขั้นที่ 1 — ตรวจ PHP ให้พร้อมก่อน

เมนู **Select PHP Version** (บางโฮสต์ชื่อ *PHP Version Selector*)

1. เลือก **PHP 8.0 ขึ้นไป** — แนะนำ 8.2
2. ติ๊กเปิดส่วนขยายเหล่านี้ให้ครบ แล้วกด Save

| ส่วนขยาย | ใช้ทำอะไร | ถ้าขาด |
|---|---|---|
| `pdo_mysql` | เชื่อมต่อฐานข้อมูล | ติดตั้งไม่ได้เลย |
| `mbstring` | ตัดข้อความภาษาไทย | ข้อความไทยเพี้ยน/ตัดคำผิด |
| `gd` | ย่อและครอบตัดรูป | อัปโหลดรูปไม่ได้ |
| `fileinfo` | ตรวจชนิดไฟล์ที่อัปโหลด | อัปโหลดไฟล์แนบไม่ได้ |
| `zip` | อัปเดต / สำรองข้อมูล / โอนย้ายเว็บ | ใช้ระบบอัปเดตในตัวไม่ได้ |
| `openssl` | ตรวจลายเซ็นแพ็กเกจอัปเดต | ใช้ระบบอัปเดตในตัวไม่ได้ |

ข้ามขั้นนี้ได้ถ้าไม่แน่ใจ — ตัวติดตั้งจะตรวจให้เองและบอกว่าขาดอะไร (ดูขั้นที่ 5)

---

## ขั้นที่ 2 — สร้างฐานข้อมูล

เมนู **MySQL Management** → **Create new Database**

| ช่อง | ใส่อะไร |
|---|---|
| Database Name | `alicecms` |
| Database Username | `alicecms` |
| Password | กด **Random** แล้ว**คัดลอกเก็บไว้** |

**สำคัญ:** DirectAdmin จะเติมชื่อบัญชีโฮสต์ไว้ข้างหน้าให้อัตโนมัติ
สมมติบัญชีโฮสต์ชื่อ `tsdpolice` ค่าจริงที่ได้จะเป็น

```
ชื่อฐานข้อมูล : tsdpolice_alicecms
ชื่อผู้ใช้     : tsdpolice_alicecms
Host          : localhost
```

**ต้องจดชื่อเต็มที่มีคำนำหน้าไปใช้ตอนติดตั้ง** — นี่คือจุดที่คนพลาดบ่อยที่สุด ถ้ากรอกแค่ `alicecms`
จะเชื่อมต่อไม่ได้ และ AliceCMS สร้างฐานข้อมูลเองไม่ได้บนโฮสต์แบ่งปัน เพราะบัญชีไม่มีสิทธิ์ระดับนั้น

---

## ขั้นที่ 3 — อัปโหลดไฟล์

1. โหลด **`alicecms-x.y.z.zip`** จาก [หน้า Releases](https://github.com/minihikkie/alicecms/releases/latest)
   (โหลดไฟล์ `.zip` ของรุ่น ไม่ใช่ปุ่ม *Download ZIP* สีเขียวของ GitHub ซึ่งเป็นซอร์สโค้ดดิบและมีโฟลเดอร์ครอบอยู่ชั้นหนึ่ง)
2. เมนู **File Manager** → เข้าไปที่ `domains/ชื่อโดเมนของคุณ/public_html`
3. **เปิดการแสดงไฟล์ซ่อนก่อน** — ปุ่มหรือเมนู *Show hidden files (dotfiles)*
   ถ้าไม่เปิด จะไม่เห็นไฟล์ `.htaccess` และจะเข้าใจผิดว่าแตกไฟล์ไม่ครบ
4. กด **Upload** เลือกไฟล์ zip → เสร็จแล้วกด **Extract**

ไฟล์ในแพ็กเกจถูกจัดไว้แบบ**ไม่มีโฟลเดอร์ครอบ** แตกแล้วต้องเห็นหน้าตาแบบนี้ที่ `public_html` เลย

```
public_html/
├── .htaccess          ← ไฟล์ซ่อน ต้องมี ห้ามลบ
├── index.php
├── install.php
├── admin/
├── assets/
├── includes/
└── docs/
```

ถ้าเห็นเป็น `public_html/alicecms-1.45.0/...` แสดงว่ามีโฟลเดอร์ครอบเกินมา —
ให้เข้าไปในโฟลเดอร์นั้น เลือกทั้งหมด แล้ว **Move** ออกมาไว้ที่ `public_html` ชั้นบนสุด

> **ลบไฟล์เว็บเดิมออกก่อน** ถ้าใน `public_html` มีเว็บเก่าอยู่ (เช่น WordPress)
> โดยเฉพาะ `index.php` และ `.htaccess` เดิม ไม่งั้นจะชนกัน

### เรื่องสิทธิ์ไฟล์

DirectAdmin รัน PHP ในนามบัญชีผู้ใช้ของคุณอยู่แล้ว ปกติจึงเขียนไฟล์ได้เลยไม่ต้องตั้งอะไร
ถ้าตัวติดตั้งฟ้องว่าเขียนไม่ได้ ให้เลือกโฟลเดอร์ `public_html` → **Set Permissions** → โฟลเดอร์ `755` ไฟล์ `644`

**ห้ามตั้ง 777** ไม่ว่าคู่มือของที่อื่นจะบอกอย่างไร — บนโฮสต์แบ่งปัน 777 แปลว่าบัญชีอื่น
บนเครื่องเดียวกันเขียนทับไฟล์เว็บคุณได้

## ขั้นที่ 4 — เปิด HTTPS

เมนู **SSL Certificates** → เลือก **Free & automatic certificate from Let's Encrypt** → Save

เสร็จแล้วกลับไปที่ **Domain Setup** → ติ๊ก **Force SSL with https redirect**

ทำขั้นนี้**ก่อน**ติดตั้ง จะดีกว่าทำทีหลัง เพราะตัวติดตั้งจำที่อยู่เว็บตอนนั้นไว้ใช้ต่อ
และหน้าเข้าสู่ระบบผู้ดูแลไม่ควรวิ่งผ่าน http เปล่าๆ ตั้งแต่ครั้งแรก

---

## ขั้นที่ 5 — รันตัวติดตั้ง

เปิดเบราว์เซอร์ไปที่

```
https://โดเมนของคุณ/install.php
```

หน้าแรกจะ**ตรวจความพร้อมของเซิร์ฟเวอร์ให้ก่อน** — ถ้ามีรายการไหนขึ้นกากบาทสีแดง
ให้กลับไปแก้ที่ขั้นที่ 1 แล้วรีเฟรช อย่าเพิ่งติดตั้งทั้งที่ยังแดง

จากนั้นทำตาม 4 ขั้น

| ขั้น | กรอกอะไร |
|---|---|
| 1. ฐานข้อมูล | Host `localhost` · ชื่อฐานข้อมูล/ผู้ใช้ **ที่มีคำนำหน้า** จากขั้นที่ 2 |
| 2. ข้อมูลหน่วยงาน | ชื่อหน่วยงาน สังกัด โลโก้ |
| 3. ธีม | สีประจำหน่วยงาน และเลือกว่าจะเปิดส่วนไหนบ้าง |
| 4. บัญชีผู้ดูแล | ชื่อผู้ใช้ 4–50 ตัว · รหัสผ่านอย่างน้อย 8 ตัว |

ตัวติดตั้งจะสร้างตาราง สร้าง `config.php` สร้างโฟลเดอร์ `uploads/` พร้อมไฟล์ป้องกัน
แล้วสร้าง `install.lock` เพื่อกันคนอื่นรันติดตั้งซ้ำ — **อย่าลบไฟล์ `install.lock`**

## ขั้นที่ 6 — ตรวจหลังติดตั้ง

เข้าหน้าจัดการที่ `https://โดเมนของคุณ/admin/` — **ไม่มีลิงก์จากหน้าเว็บ ต้องพิมพ์ URL เอง**

เช็กลิสต์:

- [ ] หน้าแรกเปิดได้ ไม่มีข้อความ error
- [ ] เข้า `/admin/` แล้วล็อกอินได้
- [ ] ลองอัปโหลดรูปในข่าวสักชิ้น ถ้าอัปโหลดไม่ได้แปลว่าสิทธิ์โฟลเดอร์ `uploads/` ยังไม่ถูก
- [ ] เปิด `https://โดเมน/config.php` แล้วต้องขึ้น **403 Forbidden** (ถ้าโหลดไฟล์ลงมาได้ = `.htaccess` ไม่ทำงาน หยุดใช้ทันทีแล้วแจ้งโฮสต์)
- [ ] ตั้งค่า → เปิด **ยืนยันตัวตน 2 ชั้น (2FA)** ให้บัญชีผู้ดูแล

### URL สวย (ซ่อน `.php`)

DirectAdmin ส่วนใหญ่ใช้ Apache หรือ LiteSpeed ซึ่งอ่าน `.htaccess` ได้ ฟีเจอร์นี้จึงใช้ได้เลย
เปิดที่ **ตั้งค่าเว็บไซต์ → URL แบบซ่อน .php** ระบบจะทดสอบเซิร์ฟเวอร์ให้ก่อนเปิดเสมอ
ถ้าโฮสต์ไม่รองรับ ระบบจะไม่เปิดให้และแจ้งเตือน — เว็บยังใช้งานได้ปกติ แค่ URL มี `.php`

## ขั้นที่ 7 — สำรองข้อมูล

**วิธีที่ง่ายที่สุด** — ตั้งที่ ตั้งค่า → สำรองข้อมูล ให้สำรองอัตโนมัติ ระบบจะสำรองให้เอง
เมื่อผู้ดูแลเปิดหน้าจัดการและถึงรอบแล้ว ไม่ต้องตั้ง cron

**ถ้าอยากให้สำรองตรงเวลาแม้ไม่มีใครเข้าหน้าแอดมินเลย** ต้องใช้ไฟล์ `tools/cron-backup.php`
ซึ่ง **ไม่ได้มากับแพ็กเกจ `.zip`** (ตั้งใจตัดออกเพราะเป็นเครื่องมือฝั่งผู้พัฒนา)
ให้โหลดไฟล์นั้นจาก [ซอร์สโค้ดบน GitHub](https://github.com/minihikkie/alicecms/blob/main/tools/cron-backup.php)
มาวางที่ `public_html/tools/` เอง แล้วตั้งที่เมนู **Cron Jobs**

```
0 3 * * *  /usr/local/bin/php /home/ชื่อบัญชี/domains/โดเมน/public_html/tools/cron-backup.php
```

> ที่อยู่ของ `php` ต่างกันไปตามโฮสต์ (`/usr/local/bin/php` หรือ `/usr/bin/php`)
> ถ้าไม่แน่ใจให้ถามผู้ให้บริการ

**อย่าพึ่งการสำรองของโฮสต์อย่างเดียว** — ควรกดดาวน์โหลดไฟล์สำรองเก็บไว้นอกเซิร์ฟเวอร์เป็นระยะ
ไฟล์สำรองมีทั้งรหัสผ่านผู้ดูแล (แบบเข้ารหัส) และ**ข้อมูลส่วนบุคคลของประชาชนที่ร้องเรียนเข้ามา**
ต้องเก็บให้ปลอดภัยตาม พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล

## ขั้นที่ 8 — เปิดระบบอัปเดตในตัว

ตั้งค่า → **อัปเดตระบบ** → กรอก URL นี้ครั้งเดียว

```
https://github.com/minihikkie/alicecms/releases/latest/download/update.json
```

จากนั้นกดอัปเดตจากหน้าแอดมินได้เลย ไม่ต้องขึ้น FTP อีก ระบบจะสำรองของเดิมไว้ก่อนเสมอ
และตรวจลายเซ็นดิจิทัลของแพ็กเกจก่อนติดตั้ง ถ้าลายเซ็นไม่ผ่านจะไม่ติดตั้งให้

> **เครือข่ายราชการบางแห่งปิดการเชื่อมต่อออกอินเทอร์เน็ต** ถ้ากดตรวจสอบอัปเดตแล้วไม่ตอบสนอง
> แปลว่าเซิร์ฟเวอร์ต่อ github.com ไม่ได้ — ยังอัปเดตได้ด้วยการอัปโหลดไฟล์ zip เองที่หน้าเดียวกัน

## ปัญหาที่พบบ่อยบน DirectAdmin

| อาการ | สาเหตุและวิธีแก้ |
|---|---|
| เปิดเว็บแล้วเจอ **500 Internal Server Error** | มักเป็นเพราะ PHP ต่ำกว่า 8.0 — ไปเปลี่ยนที่ Select PHP Version |
| เปิดเว็บแล้ว **ดาวน์โหลดไฟล์ .php ลงมาแทนที่จะแสดงผล** | โดเมนยังไม่ได้ผูกกับ PHP handler แจ้งผู้ให้บริการ |
| ติดตั้งแล้วฟ้อง **เชื่อมต่อฐานข้อมูลไม่สำเร็จ** | ลืมใส่คำนำหน้าชื่อบัญชีในชื่อฐานข้อมูล/ผู้ใช้ (ดูขั้นที่ 2) |
| **อัปโหลดรูปไม่ได้** ทั้งที่ติดตั้งผ่าน | โฟลเดอร์ `uploads/` เขียนไม่ได้ → Set Permissions เป็น 755 |
| **หน้าเว็บขึ้น แต่ `/admin/` ไม่ขึ้น** | แตกไฟล์ไม่ครบ ตรวจว่ามีโฟลเดอร์ `admin/` จริง |
| **เข้าหน้าแอดมินแล้วเด้งออกทุกครั้ง / เซสชันหมดอายุตลอด** | พื้นที่โฮสต์เต็ม ทำให้เขียนไฟล์เซสชันไม่ได้ → ลบไฟล์สำรองเก่าใน `storage/backups/` |
| URL สวยเปิดไม่ได้ | โฮสต์ไม่ได้เปิด `AllowOverride` แจ้งผู้ให้บริการ หรือใช้แบบมี `.php` ต่อไป |
| อัปเดตแล้ว **แตกไฟล์ไม่สำเร็จ** | พื้นที่เต็ม หรือไม่มีส่วนขยาย `zip` |

## ย้ายเว็บเดิมมา DirectAdmin

ถ้าเคยติดตั้ง AliceCMS ไว้ที่อื่นแล้วอยากย้าย ใช้เมนู **โอนย้ายเว็บ** ในหน้าแอดมินของเว็บเดิม
ดาวน์โหลดไฟล์ย้ายออกมา แล้วติดตั้ง AliceCMS ใหม่ที่ DirectAdmin ตามคู่มือนี้
จากนั้นนำไฟล์ไปนำเข้าที่เมนูเดียวกัน — ได้ทั้งเนื้อหา รูป และการตั้งค่า
