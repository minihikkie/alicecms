# รูปแบบไฟล์นำเข้าสารบัญแบบหนังสือ (doc-book JSON)

ใช้กับหน้า **admin → เอกสารเผยแพร่ → จัดการสารบัญ** (`admin/doc-book.php?cat=<id>`)
สำหรับใส่หัวข้อจำนวนมากในครั้งเดียว เช่น ประมวลระเบียบการตำรวจไม่เกี่ยวกับคดีทั้ง 58 ลักษณะ

ระบบตรวจทั้งไฟล์ก่อนนำเข้า ถ้าพบจุดผิดแม้แต่จุดเดียวจะไม่นำเข้าเลย และแสดงตำแหน่งที่ผิด
(เช่น `items[11].children[3]: kind ต้องเป็น part / chapter / amend`)
การนำเข้าแบบ "แทนที่" จะสำรองสารบัญเดิมเป็นไฟล์ไว้ก่อนเสมอ กู้คืนได้จากหน้าเดียวกัน

## โครงสร้าง

```json
{
  "format": "alicecms-docbook",
  "version": 1,
  "items": [
    {
      "kind": "part",
      "label": "ลักษณะที่ 4",
      "title": "การบรรจุ พ.ศ. 2556",
      "url": "https://drive.google.com/file/d/XXXX/view",
      "children": [
        {
          "kind": "chapter",
          "label": "บทที่ 1",
          "title": "การบรรจุบุคคลเป็นข้าราชการตำรวจ",
          "children": [
            {
              "kind": "amend",
              "label": "ฉบับที่ 2",
              "title": "(พ.ศ. 2557) การพิจารณาผู้ประพฤติเสื่อมเสียหรือบกพร่องในศีลธรรมอันดี (เพิ่มเติมข้อ 7 บทที่ 1)",
              "url": "https://drive.google.com/file/d/YYYY/view"
            }
          ]
        },
        {
          "kind": "amend",
          "label": "ฉบับที่ 3",
          "title": "(พ.ศ. 2559) เพิ่มบทที่ 5 และบทที่ 6",
          "url": "https://drive.google.com/file/d/ZZZZ/view"
        }
      ]
    },
    {
      "kind": "part",
      "label": "ลักษณะที่ 2",
      "title": "การปกครองบังคับบัญชา",
      "status": "repealed",
      "note": "ยกเลิกโดยคำสั่ง ตร. ที่ 267/2556 ลง 26 เม.ย. 2556"
    }
  ]
}
```

ลำดับใน `items` และ `children` คือลำดับที่แสดงบนหน้าเว็บ

## ฟิลด์

| ฟิลด์ | จำเป็น | ความหมาย |
|---|---|---|
| `kind` | ✓ | `part` = ลักษณะ · `chapter` = บท · `amend` = ฉบับแก้ไขเพิ่มเติม |
| `label` | ✓* | ป้ายเลข เช่น `ลักษณะที่ 4`, `บทที่ 1`, `ฉบับที่ 2` (ไม่เกิน 80 ตัวอักษร) |
| `title` | ✓* | ชื่อเรื่อง (ไม่เกิน 500 ตัวอักษร) |
| `status` | | `active` (ค่าเริ่มต้น) หรือ `repealed` = ยกเลิกแล้ว — ใช้กับลักษณะและบท |
| `note` | | หมายเหตุ เช่น คำสั่งที่ยกเลิก (ไม่เกิน 500 ตัวอักษร) |
| `url` | | ลิงก์เอกสาร ต้องขึ้นต้นด้วย `http://` หรือ `https://` |
| `document_id` | | เลขของเอกสารที่อัปโหลดไว้แล้ว **ในหมวดเดียวกัน** (ดูเลขได้จากลิงก์ "แก้ไข" ในหน้าเอกสารเผยแพร่ `?edit=<เลข>`) ถ้าใส่ทั้งคู่ ระบบใช้ `document_id` ก่อน ถ้าไม่พบเอกสารจะเตือนแล้วนำเข้าโดยไม่ผูก |
| `children` | | หัวข้อย่อย |

\* ต้องมี `label` หรือ `title` อย่างน้อยหนึ่งอย่าง

## กฎโครงสร้าง

- ระดับบนสุด (`items`) เป็น `part` เท่านั้น
- ใต้ `part` ได้ `chapter` และ `amend`
- ใต้ `chapter` ได้ `amend` เท่านั้น
- `amend` ไม่มีหัวข้อย่อย
- ฉบับแก้ไขที่แก้บทเดียว ให้วางใต้บทนั้น · ฉบับที่แก้หลายบทหรือทั้งลักษณะ ให้วางใต้ลักษณะ
- ไฟล์หนึ่งมีได้ไม่เกิน 5,000 หัวข้อ และขนาดไม่เกิน 5 MB

## ข้อควรระวังเวลาแปลงจากเอกสารต้นฉบับ

- ตัดหมายเหตุภายในของผู้จัดทำออก (เช่น ข้อความหลังเครื่องหมาย `***` หรือคำถามที่เขียนไว้เตือนตัวเอง) เพราะจะขึ้นบนเว็บสาธารณะตามที่เขียน
- คำว่า "(ยกเลิกโดย…)" ท้ายชื่อลักษณะหรือบท ให้ย้ายไปไว้ใน `note` แล้วตั้ง `status` เป็น `repealed` — ชื่อเรื่องจะได้สะอาด
- เลขไทย (๑ ๒ ๓) ใช้ได้ ช่องค้นหาบนหน้าเว็บค้นได้ทั้งเลขไทยและเลขอารบิก
- ปุ่ม "ส่งออกสารบัญปัจจุบัน" ในหน้าเดียวกันให้ไฟล์รูปแบบนี้ ใช้เป็นตัวอย่างหรือแก้แล้วนำเข้ากลับได้
